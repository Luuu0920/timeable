使用说明

课表和计划放在同一张周视图里。数据只存在你这台设备上： 不上传、不用登录，别人看不到你的，你也看不到别人的。下面从「能做什么」讲到「怎么录自己的课」， 按顺序看一遍，十分钟就能用顺手。

一、这款 App 能做什么

  • 一张周视图看全周：上课、健身、考试、待办、活动，按类型用不同颜色区分，一眼看清。
  • 纯本地、免登录：不用注册、不用联网；装到桌面后断网也能打开。
  • 录入不难：一行一门课就能批量导入；也能导入 WakeUp 备份，或者让 AI 帮你把课表转成它的格式。
  • 数据能带走：导出 JSON 备份换手机，导出 ICS 塞进系统日历（由系统负责提醒）。
  • 该有的都有：首页考试倒计时横幅、待办勾选、按周重复的事项。

二、五个页面分别管什么

  • 日历：主视图。顶部可切「周视图 / 日视图」；点空白格 = 新建，点已有卡片 = 编辑；左右滑动 = 切周。
  • 课表：管理课程本身 —— 手动添加、编辑、删除、批量粘贴录入、导入导出课表。
  • 计划：四类个人事项 —— 待办（可勾选）/ 健身 / 考试（自动倒计时）/ 活动。
  • 说明：就是本页。
  • 设置：学期起始日、总周数、作息时间表、备份与恢复、清空数据。

三、装到手机桌面

装到桌面后是全屏无地址栏的，能离线打开，也更像原生 App。建议第一步就做。

  • Android：浏览器菜单 ⋮ →「安装应用」/「添加到主屏幕」。
  • iPhone：必须用 Safari → 底部「分享」→「添加到主屏幕」。
    （微信里打开加不了：先点右上角 ··· →「在浏览器中打开」，再用 Safari 加）

四、录入你自己的课表（三种方式）

！这一步不做，App 等于没法用 —— 不先设「学期起始日」， 所有课的周次、单双周、考试倒计时全都会错。请先去「设置」把学期起始日改成 你们学校第 1 周的星期一（几月几号），确认无误再录课。

顺序别搞反，先做前两步：

  1. 「设置」→ 学期起始日 改成你们学校第 1 周的星期一。
    （填错了所有周次、单双周都会歪，务必先确认这一步）
  2. 「设置」→ 清空所有数据，清掉预置的示例课表（作息时间表会保留）。
节次和上下课时间，按你们学校的来。 每个学校一天几节课、几点上课都不一样，所以「设置 → 上课时间表」里可以 加/减一天几节课、改每一节的时间。如果你的课排在第 11-13 节这种晚课， 把「一天几节课」加上去、再把时间改成你们学校的即可。 就算忘了改，App 也会照你的作息节奏自动补齐节次（不会把第 11 节的课画到第 1 节去）， 只是推算出来的时间需要你去核对一下。

方式 1 · 手动添加
课表页 →「+ 手动添加课程」，逐项填写。课不多时最直观。

方式 2 · 批量粘贴（推荐）
课表页 →「批量粘贴录入」，一行一门课，每行的格式是：

课程名 周几 第几节-第几节 周次 地点
高等数学 周一 1-2节 1-16周 教三201
大学英语 周三 3-4节 单周 外语楼A101
体育 周五 5-6节 1-18周 操场
  • 周几写 周一～周日；节次写 1-2节、3-4节 这种。
  • 周次写 1-16周；只有单周写 单周，只有双周写 双周；周次不连续就拆成几行。
  • 地点可以省略；同一门课一周上多次，每次单独一行。
  • 不确定就先点「先检查一下」，它会告诉你哪几行没认出来，改完再导入。

方式 3 · 导入 WakeUp 课表
如果你在用 WakeUp 这类 App，先在它里面「导出为备份」，拿到 .wakeup_schedule 文件， 再来「设置 → 导入 WakeUp 课表」选它即可。

五、懒人捷径：让 AI 帮你转格式

手里只有课表的截图 / PDF / Excel，懒得手动敲？把下面这段话连同你的课表一起发给任意一个 AI （豆包、Kimi、DeepSeek、ChatGPT 都行），它会把课表整理成上面那种「一行一门课」的文本， 你复制回来粘进「批量粘贴录入」就能用。

你是一个课表整理助手。下面我会给你一份大学课表（可能是截图里的文字、Excel 粘贴的内容或表格）。
请把它整理成「一行一门课」的纯文本，除此之外不要输出任何解释。

每行的格式是：
课程名 周几 第几节-第几节 周次 地点

规则：
- 周几只能写：周一 周二 周三 周四 周五 周六 周日
- 节次写成「1-2节」「3-4节」这种，连着上的节次用 - 连起来
- 周次写「1-16周」；只有单周写「单周」，只有双周写「双周」；周次不连续就拆成几行
- 一门课一周上多次，每次单独一行
- 地点有就写、没有就省略
- 只输出这些行，不要标题、不要编号、不要解释

示例输出：
高等数学 周一 1-2节 1-16周 教三201
大学英语 周三 3-4节 单周 外语楼A101

更快的一条路：让 AI 直接转成 .ics 文件（推荐）
上面那条要复制两回文字，这条只需要一个文件，点几下就完事：

  1. 把你的课表截图（或 Excel、PDF 文件）发给任意一个 AI —— 豆包、Kimi、DeepSeek、ChatGPT 都行。
  2. 复制下面这段话，也发给它。
  3. 它会回你一大段以 BEGIN:VCALENDAR 开头、END:VCALENDAR 结尾的文字， 这就是 .ics 文件的全部内容，整段复制。
  4. 把这段文字存成文件（文件名随意，但扩展名必须是 .ics）：
    • 电脑：右键新建文本文档 → 粘贴进去 → 另存为 course.ics（保存类型选「所有文件」）。
    • 手机：粘进备忘录或 WPS，导出／分享时把文件名改成 course.ics； 实在改不了扩展名，就把内容发到电脑上再存。
  5. 回到本 App：「设置」→「导入 / 恢复」→ 点「导入 ICS」，选中刚存的文件。
  6. 导入后到周视图扫一眼；上课时间不对就去「设置 → 上课时间表」调整。
你是一个课表转换助手。下面我会给你我的大学课表（可能是截图、Excel 或 PDF 里的内容），
请把它转换成标准的 iCalendar（.ics）日历文件内容，输出从 BEGIN:VCALENDAR 开始、
到 END:VCALENDAR 结束的纯文本，除此之外不要输出任何解释。

我这边的基本信息（换算日期和时间都必须基于它们）：
- 本学期第 1 周的星期一是：【填日期，例如 2026-09-14】
- 每节课的上下课时间：【照你们学校的作息填，例如：第1节 08:00-08:45，第2节 08:55-09:40，第3节 10:00-10:45……】

转换规则：
- 每门课的每个上课时段，输出一个 VEVENT
- DTSTART 写这门课「第一次上课」那天的日期 + 该节次的开始时间；DTEND 写该节次的结束时间
- 用 RRULE:FREQ=WEEKLY;UNTIL=... 表示上到第几周，UNTIL 取最后一周那次课的日期（宁多一天、别少一天）
- 只有单周的课：RRULE 里加 INTERVAL=2，DTSTART 从第 1 周算起
- 只有双周的课：RRULE 里加 INTERVAL=2，DTSTART 从第 2 周算起
- SUMMARY 写课程名，LOCATION 写地点，DESCRIPTION 可写「第X-Y节」
- 时间写成 20260914T080000 这种格式（本地时间即可，不用加时区）

只输出 .ics 文件内容，不要任何解释。

六、日常使用：新增 / 编辑 / 删除

  • 新增：周视图点空白格；或点右下角 +；或各列表页右上角的 +。
  • 编辑：点任意一张卡片 / 列表项，弹出编辑层改内容。
  • 删除：打开编辑层，拉到底点「删除」。
  • 待办：点左侧圆圈就能勾掉；设置成每周重复的待办，这周勾了不影响下周。
  • 考试：录入考试日期后，首页顶部会自动出现倒计时横幅。
  • 临时调课：某一次课换时间或地点，进课程编辑后对该次单独调整，不影响整学期。

七、备份 / 换手机

！数据只存在你这台设备的浏览器里 —— 换手机、换浏览器、清缓存、卸载，都可能让它全部丢失且无法找回。 换手机、换学期前，务必「设置」→「导出 JSON 备份」，把文件存网盘或发给自己。
  • 「设置」→「导出 JSON 备份」，把文件存网盘或发给自己。
  • 换新设备：打开同一个链接 →「设置」→「恢复 JSON 备份」，选那个文件即可。
  • 想把课表放进系统日历（获得可靠提醒）：「设置」→「导出 ICS」。

八、常见问题

加到桌面了，打开还有地址栏？ 多半加成了书签。删掉重来，改用浏览器菜单里的「添加到主屏幕」。
周次 / 单双周显示不对？ 「设置」里的学期起始日填错了，改成第 1 周的星期一即可。
想要到点提醒我，该怎么做？ 本 App 不弹系统通知（网页的提醒不可靠，会被浏览器杀掉）。要提醒就把课表 「设置 → 导出 ICS 日历」导进手机自带日历，让系统日历负责提醒——那才是可靠的。 App 内的考试倒计时横幅、待办勾选不受影响。
能同步到电脑或别人手机吗？ 不能。每个人的数据各自存在自己设备里，互不相通 —— 这也正是它不用登录、不会泄露的原因。
换学期了怎么办？ 「设置」改学期起始日与总周数；旧课表可先「导出 JSON 备份」留底，再清空重录。

设置与数据

学期设置

所有"第 X 周"都以这一天为基准推算。改这里会整体平移教学周。

上课时间表（节次 → 时间）

序号就是"第几节"，课程的起止时间由节次推出。加减节次或改时间，全课表同步更新。

导出备份

换手机、换学期前请务必导出一次。JSON 用于本 App 完整恢复，ICS 可导入系统日历 / Google / 苹果日历。
从该日期所在周起，往后导出指定周数。

导入 / 恢复

支持 .wakeup_schedule（WakeUp「导出为备份」）、.ics、以及本 App 导出的 .json。
没有现成文件？把课表截图发给你的 AI（豆包 / Kimi / DeepSeek 都行），说「帮我转成 .ics 日历文件」， 把它给的内容存成 course.ics 再点上方「导入 ICS」。手把手教程见底部「说明」页。
